# Project Instruction — NomNom

## Technical
[V1.0.0] Tech stack: HTML/CSS/JS thuần, không dùng framework, không build tool.
[V1.0.0] Dữ liệu runtime lưu qua localStorage của trình duyệt; file JSON trong `data/` là dữ liệu mẫu/seed ban đầu.
[V1.0.0] Chạy local (mở file HTML trực tiếp hoặc qua live-server), chưa cần server dùng chung nhiều người ở bản MVP.

## Product
[V1.0.0] Không phân quyền — mọi user thao tác như nhau.
[V1.0.0] Loại hoạt động rủ không giới hạn cố định (ăn trưa/tối/trà sữa/cà phê/khác).

## UI/UX
[V1.0.0] Giao diện ưu tiên thân thiện, dùng tốt trên điện thoại (mobile-friendly).
